Contratar a Twilio — Voice (VoIP) + WhatsApp Business API

Passo a passo para abrir a conta na Twilio e habilitar os dois canais avaliados para o Argos: chamadas (Voice) e WhatsApp. Guia operacional — não é um roteiro de código.

1. Visão geral

A Twilio oferece Voice e WhatsApp Business API na mesma conta e console, então dá para contratar uma vez só e usar para os dois canais. Isso simplifica billing e reaproveita o mesmo padrão de integração (webhook + Access Token) já desenhado para o CRM.

O que a Twilio não elimina: para o WhatsApp, a verificação da conta Meta Business Manager (CNPJ, 2FA, número dedicado) continua obrigatória. A Twilio atua como intermediária (BSP) e tem um fluxo assistido — o Embedded Signup — que agiliza o cadastro, mas não pula a análise da Meta.

Para Voice, não há essa dependência: a compra do número e a ativação de chamadas são só com a Twilio.

2. Criar a conta Twilio

1

Cadastro inicial

Acesse twilio.com/try-twilio e crie a conta com um e-mail corporativo da GD Conecta. Confirme o e-mail e verifique o telefone (chega um código por SMS).

2

Onboarding

A Twilio pergunta "o que você quer construir" — pode escolher a opção genérica ou pular; isso só ajusta sugestões na tela inicial, não trava nada.

3

Conta trial vs. paga

A conta começa em modo trial, com crédito grátis (cerca de US$15) — dá para testar Voice sem cartão, mas só liga para números já verificados manualmente e insere um aviso de voz nas chamadas.

Para produção, faça o upgrade adicionando um cartão (Console → Billing → Upgrade). Isso remove as limitações do trial.

3. Configurar Voice (VoIP)

3.1 Comprar o númeroVoice

1

Console → Phone Numbers → Buy a Number. Filtre por país Brasil (BR) e capacidade "Voice".

Atenção: comprar um número brasileiro na Twilio exige o preenchimento de um Regulatory Compliance Bundle — documentos da empresa e comprovante de endereço, exigidos pela Anatel. É um processo bem mais rápido que a verificação da Meta (normalmente 1 a 3 dias úteis), mas não é instantâneo.

Se precisar testar antes disso, dá para usar um número dos EUA/virtual só para originar chamadas de saída enquanto o bundle BR é analisado.

3.2 Gerar credenciais

1

Account SID e API Key

Console → Account → API keys & tokens: anote o Account SID e crie uma API Key/API Secret nova (não reaproveitar a Auth Token principal em produção).

Essas credenciais são o que o backend do CRM usa para gerar o Access Token que o navegador consome via Twilio.Device (WebRTC) — o desenho técnico já está avaliado, só falta plugar os valores reais quando o número estiver aprovado.

4. Configurar WhatsApp Sender WhatsApp

4.1 Sandbox (teste rápido, não é produção)

1

Console → Messaging → Try it out → Send a WhatsApp message. A Twilio dá um número compartilhado de sandbox — só para testes internos de desenvolvimento, com um código que cada participante precisa enviar manualmente para "entrar" na sandbox. Não serve para atender clientes reais.

4.2 Produção — Embedded Signup

1

Criar o WhatsApp Sender

Console → Messaging → Senders → WhatsApp senders → Create new WhatsApp Sender.

2

Conectar (ou criar) a conta Meta Business Manager

O fluxo da Twilio (Embedded Signup) conduz direto para dentro da tela — não precisa ir separadamente ao Meta Business Manager antes. Se a GD Conecta ainda não tiver uma conta Meta Business, o próprio fluxo cria uma.

3

Verificação da empresa

Ainda é exigido: documentos da empresa (CNPJ, contrato social ou comprovante), ativação de 2FA na conta Meta, e um número de telefone dedicado que não tenha WhatsApp pessoal/comum ativo (pode reaproveitar o mesmo número BR comprado no passo 3, desde que esteja livre).

Prazo: o Embedded Signup costuma ser mais rápido que abrir a verificação manualmente direto no Meta Business Manager, mas ainda é variável — de poucos dias a algumas semanas, dependendo da fila de análise da Meta.

6. Depois de contratado — o que muda no CRM

V

Voice

O desenho já está pronto (Twilio.Device + Access Token gerado pelo backend). Basta plugar Account SID, API Key/Secret e o número comprado em variáveis de ambiente e ativar o piloto (1 número, só chamadas de saída) na aba Chamadas de Preferências.

W

WhatsApp

Depois do Sender aprovado, falta construir o webhook de mensagens recebidas (reaproveitando o mesmo padrão de fila usado em E-mail) e cadastrar os templates de mensagem pré-aprovados pela Meta — toda mensagem fora da janela de 24h de uma conversa iniciada pelo cliente exige um template aprovado.

7. Checklist resumido

  • Criar conta Twilio com e-mail corporativo e fazer upgrade para conta paga
  • Comprar número BR (Voice) e enviar o Regulatory Compliance Bundle
  • Gerar Account SID + API Key/Secret dedicados para o CRM
  • Abrir o WhatsApp Sender via Embedded Signup, reaproveitando o número BR
  • Reunir documentos da empresa (CNPJ, contrato social/comprovante) para a verificação Meta
  • Confirmar 2FA ativo na conta Meta Business Manager
  • Após aprovação: plugar credenciais reais no CRM e ativar o piloto de Voice
  • Após aprovação do Sender: priorizar o webhook de WhatsApp e os templates de mensagem
